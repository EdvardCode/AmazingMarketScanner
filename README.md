# Amazing Market Scanner

Программа для поиска лучшей цены продажи товаров на рынке игры **Amazing Online RP**.
Обходит 40 торговых павильонов, делает скриншоты окон продажи, распознаёт названия и цены
(цветовая детекция + Tesseract OCR) и показывает, в какой павильон выгоднее всего продать товар.

## Возможности
- Очередь из 40 павильонов: скан открытого / пометка закрытого («✕») горячими клавишами
- Распознавание карточек товара: название (белый текст) и цена (зелёная «таблетка»)
- Список целей продажи прямо в окне программы
- Итоговая таблица: лучшая цена, павильон, средняя по рынку, выгода, все цены по убыванию
- Тёмный интерфейс в стиле игры

## Горячие клавиши (по умолчанию)
| Действие | Клавиши |
|---|---|
| Скан павильона | `Ctrl+Alt+F8` |
| Павильон закрыт | `Ctrl+Alt+F7` |
| Итоги | `Ctrl+Alt+F9` |
| Сброс | `Ctrl+Alt+F10` |

Если комбинация занята другой программой, приложение само переберёт запасные
(`Ctrl+Shift+…`, `Alt+Shift+…`) и покажет актуальные в окне.

## Требования
- Windows 10/11
- Visual Studio 2022 (17.8+) с нагрузкой «Разработка классических приложений .NET»
- .NET 8 SDK
- Игра в оконном режиме или «окно без рамки» (не эксклюзивный fullscreen)

## Установка и запуск
1. Склонировать репозиторий и открыть `AmazingMarketScanner.sln` в Visual Studio 2022.
2. Построить (`Ctrl+Shift+B`) и запустить (`F5`).
   Файлы OCR (`tessdata/rus.traineddata`, `tessdata/eng.traineddata`) уже лежат в репозитории
   и автоматически копируются в выходную папку при сборке — ничего докачивать не нужно.

## Как пользоваться
1. Добавить в список «ЧТО ПРОДАЁМ» названия товаров (кавычки и «ёлочки» не важны —
   сравнение идёт по буквам и цифрам).
2. В игре открыть павильон, вкладка «Продать», нажать хоткей скана.
   Закрытый павильон — хоткей «закрыт», очередь идёт дальше.
3. После 40-го павильона итоги посчитаются автоматически.
